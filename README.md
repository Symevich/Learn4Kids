# Learn4Kids — вучым англійскую

🔗 **Жывы сайт:** https://symevich.github.io/Learn4Kids/

Дзіцячы навучальны сайт для вывучэння англійскай мовы: алфавіт, лічбы, лікі, колеры, фігуры, жывёлы.

## Раздзелы
- `index.html` — галоўная.
- `learn.html` — урокі.
- `play.html` — гульні.
- Гук — у тэчцы `audio/`.

## Тэхналогіі
HTML + CSS + JavaScript (без фрэймворкаў).

## Запуск
Статычны сайт — адкрый `index.html` або GitHub Pages.
